# Examples

Sanitized examples of a working `AI-Brain` setup. Folder names, host names, and service names have been replaced with generic equivalents — but the structure, file naming, and content patterns are real.

## `example-team/`

A small backend team's memory directory. Demonstrates:

- A 6-entry `MEMORY.md` (well within the 30-cap)
- Two `feedback_*` files: one correction-driven, one validation-driven
- One `user_*` file
- Two `reference_*` files (API gateway, Postgres conventions)
- One in-flight `project_*` (Q2 migration with checkboxes)
- A flat `INDEX.md` for quick lookups

This is roughly the size we recommend for a 1–3-person team. Org-scale users would split per project.

## What this is NOT

These examples are *not* meant to be copied verbatim. The patterns are transferable; the content is illustrative.

For drop-in starter files, see `templates/`.
