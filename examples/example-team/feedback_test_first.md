---
name: Test-first by default
description: New code requires a failing test before implementation
type: feedback
---

Write a failing test before the production code. Refactor only with green tests.

**Why:** Validated approach — the team consistently ships fewer regressions when TDD is followed. Confirmed across 3 quarters of release-quality data.

**How to apply:** All new feature work and bug fixes. Skip TDD only for: throwaway scripts, exploratory spikes, config-only changes.
